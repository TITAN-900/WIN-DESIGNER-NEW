# About interior assets

All downloaded assets are stored locally; the site makes no runtime request to Poly Haven.

- Modern Arm Chair 01 — Vibrant Nordic, Poly Haven. CC0. https://polyhaven.com/a/modern_arm_chair_01
- Rosewood Veneer 1 — Poly Haven. CC0. https://polyhaven.com/a/rosewood_veneer1
- Marble 01 — Poly Haven. CC0. https://polyhaven.com/a/marble_01
- Wood Floor — Poly Haven. CC0. https://polyhaven.com/a/wood_floor
- License: https://polyhaven.com/license

The lounge model uses 1K JPEG colour, packed roughness/occlusion/metalness and normal maps. Repeated seating shares geometry and textures. Architectural joinery, lamps, curtains and tables are authored locally in studio-sculpture-geometry.js. Their animation remains driven by the existing Scroll Lock progress.

GLTFLoader.js and BufferGeometryUtils.js are from Three.js r170 (MIT), matching the existing local Three.js version. Import paths alone were adapted for local hosting; see assets/js/vendor/three.LICENSE.txt.
