# Project Image Folders

Add future project photos in a folder named after the project slug, for example:

```text
assets/projects/mont-kiara-condo/
  cover.webp
  living-01.webp
  kitchen-01.webp
  before.webp
  after.webp
```

Then add one project object in `assets/data/projects.js`.

Use optimized WebP or JPG images where possible. Keep original client photos separately if you need archive quality.
